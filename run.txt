======================================================================
                     AURA OS — HOW TO RUN GUIDE
======================================================================

PREREQUISITES:
- Python 3.10+ (configured in venv)
- Node.js 18+ & npm
- Git

----------------------------------------------------------------------
OPTION A: RUN NATIVE WINDOWS DESKTOP VOICE AGENT APP (RECOMMENDED)
----------------------------------------------------------------------
To run the native Windows Desktop Voice application (captures your microphone directly from Windows hardware without browser restrictions):

Command:
  .\venv\Scripts\python apps/desktop/main_gui.py

Or double-click:
  run_desktop.bat

Features:
- Direct Windows Microphone audio capture (SpeechRecognition + sounddevice).
- Native SAPI5 & gTTS text-to-speech voice output.
- Live task execution checklist & console audit logs.
- Emergency STOP ALL button & mute toggles.


----------------------------------------------------------------------
OPTION B: RUN FASTAPI BACKEND & REACT WEB UI (BROWSER VERSION)
----------------------------------------------------------------------
1. Start Backend Shell (Terminal #1):
   .\venv\Scripts\python apps/shell/main.py

2. Start Web UI (Terminal #2):
   cd apps/frontend
   npm run dev
   - Web UI runs at: http://localhost:3000


----------------------------------------------------------------------
RUN UNIT & INTEGRATION TESTS
----------------------------------------------------------------------
Command:
  .\venv\Scripts\pytest
