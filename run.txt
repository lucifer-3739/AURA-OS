======================================================================
                     AURA OS — HOW TO RUN GUIDE (PHASE 3)
======================================================================

PREREQUISITES:
- Python 3.10+ (configured in venv)
- Node.js 18+ & npm
- Git

----------------------------------------------------------------------
1. RUN THE BACKEND AGENT SHELL, VOICE & BROWSER ENGINE (FastAPI)
----------------------------------------------------------------------
Open Terminal #1 in the root folder (`d:\Code\AURA OS`):

Command:
  .\venv\Scripts\python apps/shell/main.py

The backend server & automation engine will start at:
  - REST API: http://127.0.0.1:8000
  - WebSocket: ws://127.0.0.1:8000/api/ws
  - Browser Automation API: http://127.0.0.1:8000/api/browser/state
  - API Documentation: http://127.0.0.1:8000/docs


----------------------------------------------------------------------
2. RUN THE REACT DESKTOP VOICE & BROWSER FRONTEND (Vite)
----------------------------------------------------------------------
Open Terminal #2 in the frontend folder (`d:\Code\AURA OS\apps\frontend`):

Commands:
  cd apps/frontend
  npm run dev

The web desktop interface will open at:
  - Web UI: http://localhost:3000


----------------------------------------------------------------------
3. RUN UNIT & INTEGRATION TESTS
----------------------------------------------------------------------
To run the automated test suite (24 test suites covering tools, permissions, state machine, voice pipeline, and browser automation):

Command:
  .\venv\Scripts\pytest

Or run the standalone runner:
  .\venv\Scripts\python scripts/run_tests.py


----------------------------------------------------------------------
4. BROWSER AUTOMATION & VOICE COMMAND EXAMPLES
----------------------------------------------------------------------
A. Browser Control Commands (Voice or Text):
   - "Search web for React documentation."
   - "Click element Quick Start."
   - "Type React hooks into search."
   - "Read page content."
   - "Extract data table."
   - "Download documentation file."
   - "Close browser."

B. UI Browser Monitor:
   - Inspect live active tab URL bar, page title, extracted clean text, and interactive DOM elements list directly in the React UI `BrowserMonitor`.
