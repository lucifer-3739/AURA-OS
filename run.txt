======================================================================
                     AURA OS — HOW TO RUN GUIDE
======================================================================

PREREQUISITES:
- Python 3.10+ (configured in venv)
- Node.js 18+ & npm
- Git

----------------------------------------------------------------------
1. RUN THE BACKEND AGENT SHELL & VOICE ENGINE (FastAPI)
----------------------------------------------------------------------
Open Terminal #1 in the root folder (`d:\Code\AURA OS`):

Command:
  .\venv\Scripts\python apps/shell/main.py

The backend server & voice pipeline will start at:
  - REST API: http://127.0.0.1:8000
  - WebSocket: ws://127.0.0.1:8000/api/ws
  - Audio Devices API: http://127.0.0.1:8000/api/audio/devices
  - API Documentation: http://127.0.0.1:8000/docs


----------------------------------------------------------------------
2. RUN THE REACT DESKTOP VOICE FRONTEND (Vite)
----------------------------------------------------------------------
Open Terminal #2 in the frontend folder (`d:\Code\AURA OS\apps\frontend`):

Commands:
  cd apps/frontend
  npm run dev

The web desktop interface will open at:
  - Web UI: http://localhost:3000


----------------------------------------------------------------------
3. RUN UNIT & INTEGRATION TESTS
----------------------------------------------------------------------
To run the automated test suite (18 test suites):

Command:
  .\venv\Scripts\pytest

Or run the standalone runner:
  .\venv\Scripts\python scripts/run_tests.py


----------------------------------------------------------------------
4. TESTING VOICE INTERACTION & COMMANDS
----------------------------------------------------------------------
A. Voice Interaction via Microphone:
   1. Say "Hey Aura" to trigger the wake-word listener.
   2. Speak your command: "Open Visual Studio Code."
   3. Observe live transcript streaming and state progression:
      WAITING_FOR_WAKE_WORD -> WAKE_WORD_DETECTED -> LISTENING -> PROCESSING_SPEECH -> THINKING -> EXECUTING -> SPEAKING.

B. Fast-Path Interruption Commands:
   - Say "Stop talking" to halt TTS speech output instantly.
   - Say "Cancel task" to cancel the active task.
   - Say "Yes" / "No" to approve/reject pending security permission requests.

C. UI Voice Controls:
   - Click "Test Voice" in the UI to trigger a simulated end-to-end voice command run.
   - Click "Mute Mic" to toggle microphone mute.
   - Click "Stop Speech" to interrupt speech playback.


----------------------------------------------------------------------
5. GIT WORKFLOW & PUSHING A NEW BRANCH TO GITHUB
----------------------------------------------------------------------
To create a new branch and push your code to GitHub:

1. Create and switch to a new branch:
   git checkout -b feature/voice-interaction

2. Stage and commit your changes:
   git add .
   git commit -m "Update run.txt and voice features"

3. Push the new branch to GitHub:
   git push -u origin feature/voice-interaction
